Renomear DXF (Tekla/Tecno)  —  app do SISTEMA - PPCPM (tema do sistema)
====================================================================================================

Tela            : Python 3 + PyQt5 (janela Qt)
Chave no PPCP   : renomear_dxf   (mesma ferramenta do PPCP Ferramentas: MESMAS regras, só a aparência mudou — ver item 10)

1. O QUE FAZ
----------------------------------------------------------------------------------------------------
   Renomeia DXF/DWG que já foram exportados por fora (Tekla/Tecno) para o padrão do PPCP, pegando a QUANTIDADE do .CAM da mesma posição:  <posição> - OF<obra/trecho> - Q<qtd><extensão original>

2. PASSO A PASSO
----------------------------------------------------------------------------------------------------
   1. Escolha a pasta dos .CAM.
   2. Escolha a pasta dos .DXF/.DWG (sugestão inicial: Área de Trabalho\DXF). Ela é lida com subpastas.
   3. Clique em analisar: a tabela mostra nome atual, posição, quantidade, nome final e situação de cada arquivo.
   4. Confira a obra/trecho e a 'liberação' (nome da pasta acima da pasta CAM) mostrados na tela.
   5. Marque só as linhas que quer renomear e confirme. Nada é renomeado antes disso.

3. REGRAS (LÓGICA)
----------------------------------------------------------------------------------------------------
   • POSIÇÃO = nome do arquivo sem extensão (tanto do .CAM quanto do .DXF/.DWG). Casa DXF com CAM pela posição igual.
   • QUANTIDADE = QTA_PEZ do .CAM daquela posição.
   • OBRA/TRECHO = nome da pasta acima da pasta CAM, tratado pela mesma regra do Conversor (normalizar_obra: tira _L1, '_'->'-', máx. 9 dígitos).
   • Situações: ok (vai renomear) · sem_cam (não existe .CAM com essa posição) · sem_quantidade (CAM sem QTA_PEZ legível) · renomeado (feito).
   • Só troca o NOME, nunca muda de pasta. Mantém a extensão original (.dxf/.dwg).
   • Não sobrescreve arquivo que já existe com o nome final (avisa em vez de apagar).

4. TIPOS DE ARQUIVO
----------------------------------------------------------------------------------------------------
   ENTRADA 1: pasta com .CAM (só raiz)
   ENTRADA 2: pasta com .DXF e .DWG (com subpastas, qualquer maiúscula/minúscula)
   SAÍDA: os mesmos arquivos, renomeados no lugar
   Onde o código abre as janelas de escolher (arquivo:linha):
     renomear_dxf/aba.py:278
     renomear_dxf/aba.py:312

5. O QUE SAI (SAÍDAS)
----------------------------------------------------------------------------------------------------
   <mesma pasta do arquivo>\<posição> - OF<obra/trecho> - Q<qtd>.dxf (ou .dwg)

6. CAMINHOS
----------------------------------------------------------------------------------------------------
   Onde o app fica             = python\apps\Renomear_DXF\   (dentro da pasta python do SISTEMA - PPCPM)
   Pasta de DADOS (PPCP_DADOS), nesta ordem:
      1) caminho escrito à mão na 1ª linha do pasta_dados.txt (ex.: a pasta ppcp_dxf_ferramentas do servidor);
      2) a pasta de dados escolhida na tela do SISTEMA - PPCPM (python\dados_locais\producao\pasta_dados.txt,
         a mesma que o Validador de Fluxos usa dentro do sistema);
      3) padrão: python\dados_locais\producao  (criada sozinha na 1ª vez; a atualização do sistema nunca apaga dados_locais).
   Banco compartilhado         = <pasta ACIMA da pasta de dados>\pcp_projeart.db   (no padrão: python\dados_locais\pcp_projeart.db)
   Python                      = python\ferramentas\achar_python.bat do sistema (.venv do sistema, Python portátil ou o do PC)
   Cópia local do código       = %LOCALAPPDATA%\PPCP_Apps\Renomear_DXF\app   (feita pelo .bat com robocopy /MIR)
   Log deste app               = %LOCALAPPDATA%\PPCP_Apps\Renomear_DXF\logs\app_dxf_ppcp_log.txt   (variável PPCP_LOGS)
   Pasta sugerida ao abrir: %USERPROFILE%\Desktop\DXF
   Não usa banco de dados.
   Tabelas criadas pelo código: corte_arquivos, corte_eventos, corte_partes, corte_processamentos

7. COMO ABRIR
----------------------------------------------------------------------------------------------------
   • 1ª vez no PC: dois cliques em instalar_bibliotecas_Renomear_DXF.bat (usa o Python do sistema)
   • Depois: dois cliques em iniciar_Renomear_DXF.bat (copia o código pro PC e abre). Com problema: iniciar_Renomear_DXF.bat debug
   • Ou, pelo CMD dentro desta pasta: python main.py
   • Para virar .exe: pyinstaller Renomear_DXF.spec
