Espelhar DXF  —  app do SISTEMA - PPCPM (tema do sistema)
====================================================================================================

Tela            : Python 3 + PyQt5 (janela Qt)
Chave no PPCP   : espelhar   (mesma ferramenta do PPCP Ferramentas: MESMAS regras, só a aparência mudou — ver item 10)

1. O QUE FAZ
----------------------------------------------------------------------------------------------------
   Espelha DXF no eixo X (lado esquerdo <-> lado direito), recoloca o desenho começando em (0,0) e salva numa subpasta ESPELHADAS com o mesmo nome. Mostra o antes/depois na tela.

2. PASSO A PASSO
----------------------------------------------------------------------------------------------------
   1. Selecione a pasta com os DXF (só a raiz).
   2. Escolha os arquivos na lista (veja a pré-visualização do original).
   3. Clique em espelhar: aparece o antes/depois e o log.
   4. Os arquivos novos ficam em <pasta>\ESPELHADAS.

3. REGRAS (LÓGICA)
----------------------------------------------------------------------------------------------------
   • Espelhamento feito por conta própria (matemática em espelhar/mirror.py), entidade por entidade: LINE, CIRCLE, ARC (ângulos invertidos), LWPOLYLINE (bulge invertido), POLYLINE, ELLIPSE, SPLINE, POINT, faces 3D e INSERT (blocos).
   • Depois de espelhar, move tudo para o desenho começar em X=0, Y=0.
   • O original NÃO é alterado.

4. TIPOS DE ARQUIVO
----------------------------------------------------------------------------------------------------
   ENTRADA: pasta com .DXF (só raiz)
   SAÍDA: .DXF espelhado
   Onde o código abre as janelas de escolher (arquivo:linha):
     espelhar/aba.py:216

5. O QUE SAI (SAÍDAS)
----------------------------------------------------------------------------------------------------
   <pasta>\ESPELHADAS\<mesmo nome>.dxf

6. CAMINHOS
----------------------------------------------------------------------------------------------------
   Onde o app fica             = python\apps\Espelhar_DXF\   (dentro da pasta python do SISTEMA - PPCPM)
   Pasta de DADOS (PPCP_DADOS), nesta ordem:
      1) caminho escrito à mão na 1ª linha do pasta_dados.txt (ex.: a pasta ppcp_dxf_ferramentas do servidor);
      2) a pasta de dados escolhida na tela do SISTEMA - PPCPM (python\dados_locais\producao\pasta_dados.txt,
         a mesma que o Validador de Fluxos usa dentro do sistema);
      3) padrão: python\dados_locais\producao  (criada sozinha na 1ª vez; a atualização do sistema nunca apaga dados_locais).
   Banco compartilhado         = <pasta ACIMA da pasta de dados>\pcp_projeart.db   (no padrão: python\dados_locais\pcp_projeart.db)
   Python                      = python\ferramentas\achar_python.bat do sistema (.venv do sistema, Python portátil ou o do PC)
   Cópia local do código       = %LOCALAPPDATA%\PPCP_Apps\Espelhar_DXF\app   (feita pelo .bat com robocopy /MIR)
   Log deste app               = %LOCALAPPDATA%\PPCP_Apps\Espelhar_DXF\logs\app_dxf_ppcp_log.txt   (variável PPCP_LOGS)
   Não usa banco de dados. dxf_util/preview.py é o desenho da pré-visualização (o mesmo do unificador).
   Tabelas criadas pelo código: corte_arquivos, corte_eventos, corte_partes, corte_processamentos

7. COMO ABRIR
----------------------------------------------------------------------------------------------------
   • 1ª vez no PC: dois cliques em instalar_bibliotecas_Espelhar_DXF.bat (usa o Python do sistema)
   • Depois: dois cliques em iniciar_Espelhar_DXF.bat (copia o código pro PC e abre). Com problema: iniciar_Espelhar_DXF.bat debug
   • Ou, pelo CMD dentro desta pasta: python main.py
   • Para virar .exe: pyinstaller Espelhar_DXF.spec
