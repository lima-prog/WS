Visualizador DXF  —  app do SISTEMA - PPCPM (tema do sistema)
====================================================================================================

Tela            : Python 3 + PyQt5 (janela Qt)
Chave no PPCP   : visualizador   (mesma ferramenta do PPCP Ferramentas: MESMAS regras, só a aparência mudou — ver item 10)

1. O QUE FAZ
----------------------------------------------------------------------------------------------------
   Visualiza DXF um por um, bem rápido, e ajuda a SEPARAR os arquivos em pastas de fluxo (move o arquivo atual para a pasta escolhida).

2. PASSO A PASSO
----------------------------------------------------------------------------------------------------
   1. Carregue uma pasta (botão ou tecla Tab). Lista todos os .dxf da pasta.
   2. Navegue: seta direita = próximo, seta esquerda = anterior, 0 = zoom original, A = enquadrar, D = descartar da lista, Espaço = navegador de pastas.
   3. No navegador de pastas, escolha o tipo (Fluxo 1, Fluxo 2, Fluxo 3, Fluxo 4, Acessórios Padrão, Perfiladeira U E C, Perfiladeira L, Joist, Terça Z) para mover o DXF atual.
   4. Os atalhos podem ser trocados na tela de atalhos (ficam salvos para a próxima vez).

3. REGRAS (LÓGICA)
----------------------------------------------------------------------------------------------------
   • Unidade do desenho lida do cabeçalho $INSUNITS do DXF.
   • Ao escolher um tipo, cria (se não existir) a pasta '<tipo> [<espessura>]' — a espessura vem do nome da pasta atual — e MOVE o arquivo (shutil.move).
   • Se a pasta aberta já for uma pasta de fluxo, a pasta nova é criada um nível acima (ao lado dela), nunca dentro.
   • 'Descartar' (D) só tira o arquivo da lista na tela — não apaga nada do disco.
   • Enquadrar automático ao trocar de arquivo pode ser ligado/desligado (fica salvo).

4. TIPOS DE ARQUIVO
----------------------------------------------------------------------------------------------------
   ENTRADA: pasta com .DXF
   SAÍDA: o mesmo .DXF movido para a pasta de fluxo
   Onde o código abre as janelas de escolher (arquivo:linha):
     visualizador/aba.py:785

5. O QUE SAI (SAÍDAS)
----------------------------------------------------------------------------------------------------
   <pasta da obra>\<tipo> [<espessura>]\<arquivo>.dxf

6. CAMINHOS
----------------------------------------------------------------------------------------------------
   Onde o app fica             = python\apps\Visualizador_DXF\   (dentro da pasta python do SISTEMA - PPCPM)
   Pasta de DADOS (PPCP_DADOS), nesta ordem:
      1) caminho escrito à mão na 1ª linha do pasta_dados.txt (ex.: a pasta ppcp_dxf_ferramentas do servidor);
      2) a pasta de dados escolhida na tela do SISTEMA - PPCPM (python\dados_locais\producao\pasta_dados.txt,
         a mesma que o Validador de Fluxos usa dentro do sistema);
      3) padrão: python\dados_locais\producao  (criada sozinha na 1ª vez; a atualização do sistema nunca apaga dados_locais).
   Banco compartilhado         = <pasta ACIMA da pasta de dados>\pcp_projeart.db   (no padrão: python\dados_locais\pcp_projeart.db)
   Python                      = python\ferramentas\achar_python.bat do sistema (.venv do sistema, Python portátil ou o do PC)
   Cópia local do código       = %LOCALAPPDATA%\PPCP_Apps\Visualizador_DXF\app   (feita pelo .bat com robocopy /MIR)
   Log deste app               = %LOCALAPPDATA%\PPCP_Apps\Visualizador_DXF\logs\app_dxf_ppcp_log.txt   (variável PPCP_LOGS)
   Preferências no Registro do Windows (QSettings 'SuaEmpresa' / 'DXFViewer'):
      HKEY_CURRENT_USER\Software\SuaEmpresa\DXFViewer  ->  last_folder (última pasta), shortcuts (atalhos), auto_fit (enquadrar)
   Não usa banco de dados.
   Tabelas criadas pelo código: corte_arquivos, corte_eventos, corte_partes, corte_processamentos

7. COMO ABRIR
----------------------------------------------------------------------------------------------------
   • 1ª vez no PC: dois cliques em instalar_bibliotecas_Visualizador_DXF.bat (usa o Python do sistema)
   • Depois: dois cliques em iniciar_Visualizador_DXF.bat (copia o código pro PC e abre). Com problema: iniciar_Visualizador_DXF.bat debug
   • Ou, pelo CMD dentro desta pasta: python main.py
   • Para virar .exe: pyinstaller Visualizador_DXF.spec
