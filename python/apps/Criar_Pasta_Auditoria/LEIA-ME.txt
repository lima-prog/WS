Criar Pasta / Auditoria  —  app do SISTEMA - PPCPM (tema do sistema)
====================================================================================================

Tela            : Python 3 + PyQt5 (janela Qt)
Chave no PPCP   : auditoria   (mesma ferramenta do PPCP Ferramentas: MESMAS regras, só a aparência mudou — ver item 10)

1. O QUE FAZ
----------------------------------------------------------------------------------------------------
   Cria a estrutura de pastas 'LOTE <n>\<OF>' a partir da planilha de lotes, resgatando as OFs que estão na pasta 'LOTE 9999', e audita a LOTE 9999 contra a planilha. Também busca em que lote/pasta está uma obra/pacote.

2. PASSO A PASSO
----------------------------------------------------------------------------------------------------
   1. 1ª vez: tela 'Configurações' -> escolha a PLANILHA .xlsx, a PASTA onde criar os lotes e cadastre os DIRETÓRIOS RAIZ onde procurar a LOTE 9999 (ex.: K:\8.M08-2026). Fica salvo no banco (auditoria_config / auditoria_raizes).
   2. Tela 'Criar Pastas': digite o NÚMERO DO LOTE (ex.: 650) e clique em 'Criar Pastas'. O resultado mostra: resgatadas da 9999 · criadas do zero · já existentes.
   3. Tela 'Auditar Lote 9999': 'Rodar Auditoria' compara a LOTE 9999 com a planilha. Para cada problema: 'Mover p/ LOTE <n>' (vai direto pro lote da planilha) ou 'Mover para...' (você escolhe). Marque 'Mostrar também as que batem' para ver tudo.
   4. Tela 'Buscar Obra/Pacote': busca por obra (ex.: 1956 ou 1956-2-01) ou por pacote/lote (ex.: 427). 'Atualizar Base de Busca' (em Configurações) reimporta a planilha.

3. REGRAS (LÓGICA)
----------------------------------------------------------------------------------------------------
   • Planilha .xlsx: cabeçalho na LINHA 4, dados a partir da LINHA 5.
   • Colunas: A=LOTE · B=OF-TRECHO · C=ANO-SEMANA · D=PESO LIC/LOTE · E=QTD TT KG PREP · F=QTD TT KG ÑPREP · G=DATA INICIO ARTIA · H=STATUS.
   • Cria 'LOTE <n>' e dentro uma pasta para cada OF daquele lote na planilha. Se a pasta da OF já existir dentro da 'LOTE 9999' (em qualquer raiz cadastrada), ela é MOVIDA (resgatada) em vez de criar vazia.
   • Código da OF normalizado: só os 9 primeiros dígitos contam na comparação.
   • Diagnóstico da auditoria: bate (está certo) · lugar_errado (existe, mas no lote errado) · nao_encontrada (na planilha, sem pasta) · sem_registro (pasta sem linha na planilha) · duplicada (aparece mais de uma vez).
   • Pesos mostrados formatados em kg; sem peso aparece um marcador.
   • Versão do programa: VERSAO_ATUAL = 1.1.0; ao abrir compara com versao.txt para avisar de versão nova.

4. TIPOS DE ARQUIVO
----------------------------------------------------------------------------------------------------
   ENTRADA: planilha Excel (*.xlsx) escolhida em Configurações
   ENTRADA: número do lote + pasta destino dos lotes + diretórios raiz (Configurações)
   SAÍDA: pastas LOTE <n>\<OF> no disco
   Onde o código abre as janelas de escolher (arquivo:linha):
     auditoria/aba.py:833
     auditoria/aba.py:1144

5. O QUE SAI (SAÍDAS)
----------------------------------------------------------------------------------------------------
   <pasta escolhida>\LOTE <n>\<OF>\
   registros no banco (auditoria_registros)

6. CAMINHOS
----------------------------------------------------------------------------------------------------
   Onde o app fica             = python\apps\Criar_Pasta_Auditoria\   (dentro da pasta python do SISTEMA - PPCPM)
   Pasta de DADOS (PPCP_DADOS), nesta ordem:
      1) caminho escrito à mão na 1ª linha do pasta_dados.txt (ex.: a pasta ppcp_dxf_ferramentas do servidor);
      2) a pasta de dados escolhida na tela do SISTEMA - PPCPM (python\dados_locais\producao\pasta_dados.txt,
         a mesma que o Validador de Fluxos usa dentro do sistema);
      3) padrão: python\dados_locais\producao  (criada sozinha na 1ª vez; a atualização do sistema nunca apaga dados_locais).
   Banco compartilhado         = <pasta ACIMA da pasta de dados>\pcp_projeart.db   (no padrão: python\dados_locais\pcp_projeart.db)
   Python                      = python\ferramentas\achar_python.bat do sistema (.venv do sistema, Python portátil ou o do PC)
   Cópia local do código       = %LOCALAPPDATA%\PPCP_Apps\Criar_Pasta_Auditoria\app   (feita pelo .bat com robocopy /MIR)
   Log deste app               = %LOCALAPPDATA%\PPCP_Apps\Criar_Pasta_Auditoria\logs\app_dxf_ppcp_log.txt   (variável PPCP_LOGS)
   Banco: pcp_projeart.db (pasta acima de PPCP_DADOS), tabelas próprias:
      auditoria_config (caminho_planilha, caminho_destino...) · auditoria_pacotes (planilha importada p/ busca)
      auditoria_raizes (diretórios raiz cadastrados) · auditoria_registros (histórico de cada execução)
   versao.txt: na pasta acima de PPCP_DADOS (mesma do pcp_projeart.db).
   Tabelas criadas pelo código: auditoria_config, auditoria_pacotes, auditoria_raizes, auditoria_registros, corte_arquivos, corte_eventos, corte_partes, corte_processamentos

7. COMO ABRIR
----------------------------------------------------------------------------------------------------
   • 1ª vez no PC: dois cliques em instalar_bibliotecas_Criar_Pasta_Auditoria.bat (usa o Python do sistema)
   • Depois: dois cliques em iniciar_Criar_Pasta_Auditoria.bat (copia o código pro PC e abre). Com problema: iniciar_Criar_Pasta_Auditoria.bat debug
   • Ou, pelo CMD dentro desta pasta: python main.py
   • Para virar .exe: pyinstaller Criar_Pasta_Auditoria.spec
