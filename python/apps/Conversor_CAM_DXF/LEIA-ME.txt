Conversor CAM → DXF  —  app do SISTEMA - PPCPM (tema do sistema)
====================================================================================================

Tela            : Python 3 + PyQt5 (janela Qt)
Chave no PPCP   : conversor   (mesma ferramenta do PPCP Ferramentas: MESMAS regras, só a aparência mudou — ver item 10)

1. O QUE FAZ
----------------------------------------------------------------------------------------------------
   Lê os arquivos .CAM (exportados do Tekla/Tecno) de uma pasta e gera um DXF de CORTE por peça, com o nome no padrão do PPCP:  <posição> - OF<obra> - Q<quantidade>.dxf

2. PASSO A PASSO
----------------------------------------------------------------------------------------------------
   1. Clique em selecionar pasta e escolha a pasta onde estão os .CAM (só a raiz da pasta é lida, não entra em subpastas).
   2. A tabela mostra cada CAM: posição, quantidade, espessura, material, obra e tipo (PLANIFICADO ou DOBRADO).
   3. Se a obra calculada estiver errada, use 'Editar Obra' e digite a certa (vale só para a peça escolhida; 'Restaurar automático' volta ao cálculo).
   4. Marque as peças que quer converter (ou todas).
   5. Marque/desmarque 'organizar em subpastas por espessura + material'.
   6. Clique em converter e escolha a pasta de SAÍDA.
   7. No fim aparece o total convertido e a lista de erros (ex.: CAM com dobra).

3. REGRAS (LÓGICA)
----------------------------------------------------------------------------------------------------
   • Lê do bloco [HEAD] do .CAM: POS_PEZ (posição), QTA_PEZ (quantidade), LUN_PRO (comprimento), LAR_PRO (largura), SPE_PRO (espessura), MAT_PRO (material), NUM_COM (obra/comessa).
   • Bloco [SHAPE]: valor 'R' = PLANIFICADO (converte). Qualquer outro = DOBRADO -> NÃO converte (modo DOBRA não existe nesta versão; vira erro na lista).
   • Desenha no DXF: [OUTLINE] (contorno externo, linhas + arcos dos blocos LIV), [INLINE] (contornos internos), [HOLE] (furos e rasgos oblongos H). [MARK] é lido mas não vira geometria de corte.
   • DXF gerado: versão R2010, unidade MM ($INSUNITS = mm), tudo na camada (layer) 'CORTE'.
   • OBRA = nome da pasta ACIMA da pasta 'CAM' (se não houver, usa NUM_COM), tratada por normalizar_obra(): remove '_L1', '_L2'... em qualquer posição; '_' vira '-'; máximo 9 dígitos no total. Ex.: 2058-102_01_L1 -> 2058-102-01 · 2104-2-55_L1-2 -> 2104-2-55-2. Vazio -> SEM_OBRA.
   • Obra digitada à mão ('Editar Obra') tem prioridade total sobre o cálculo.
   • Nome do arquivo: '{pos} - OF{obra} - Q{qtd}.dxf'. Sem posição -> SEM_POSICAO; sem quantidade -> 1. Caracteres <>:"/\|?* viram '_'.
   • Nunca sobrescreve: se o nome já existe, grava como ' (1)', ' (2)'...
   • Subpastas (opcional): '<espessura com vírgula e 2 casas> <material>', ex.: '6,35 A572'.

4. TIPOS DE ARQUIVO
----------------------------------------------------------------------------------------------------
   ENTRADA: pasta com arquivos .CAM (qualquer maiúscula/minúscula), só o nível raiz
   SAÍDA: arquivos .DXF (R2010, mm, layer CORTE)
   Onde o código abre as janelas de escolher (arquivo:linha):
     conversor/aba.py:255
     conversor/aba.py:475

5. O QUE SAI (SAÍDAS)
----------------------------------------------------------------------------------------------------
   <pasta de saída>\<pos> - OF<obra> - Q<qtd>.dxf
   ou <pasta de saída>\<esp> <material>\<pos> - OF<obra> - Q<qtd>.dxf

6. CAMINHOS
----------------------------------------------------------------------------------------------------
   Onde o app fica             = python\apps\Conversor_CAM_DXF\   (dentro da pasta python do SISTEMA - PPCPM)
   Pasta de DADOS (PPCP_DADOS), nesta ordem:
      1) caminho escrito à mão na 1ª linha do pasta_dados.txt (ex.: a pasta ppcp_dxf_ferramentas do servidor);
      2) a pasta de dados escolhida na tela do SISTEMA - PPCPM (python\dados_locais\producao\pasta_dados.txt,
         a mesma que o Validador de Fluxos usa dentro do sistema);
      3) padrão: python\dados_locais\producao  (criada sozinha na 1ª vez; a atualização do sistema nunca apaga dados_locais).
   Banco compartilhado         = <pasta ACIMA da pasta de dados>\pcp_projeart.db   (no padrão: python\dados_locais\pcp_projeart.db)
   Python                      = python\ferramentas\achar_python.bat do sistema (.venv do sistema, Python portátil ou o do PC)
   Cópia local do código       = %LOCALAPPDATA%\PPCP_Apps\Conversor_CAM_DXF\app   (feita pelo .bat com robocopy /MIR)
   Log deste app               = %LOCALAPPDATA%\PPCP_Apps\Conversor_CAM_DXF\logs\app_dxf_ppcp_log.txt   (variável PPCP_LOGS)
   Não usa banco de dados nem arquivo fixo: só a pasta de CAM e a pasta de saída que você escolhe na tela.
   Tabelas criadas pelo código: corte_arquivos, corte_eventos, corte_partes, corte_processamentos

7. COMO ABRIR
----------------------------------------------------------------------------------------------------
   • 1ª vez no PC: dois cliques em instalar_bibliotecas_Conversor_CAM_DXF.bat (usa o Python do sistema)
   • Depois: dois cliques em iniciar_Conversor_CAM_DXF.bat (copia o código pro PC e abre). Com problema: iniciar_Conversor_CAM_DXF.bat debug
   • Ou, pelo CMD dentro desta pasta: python main.py
   • Para virar .exe: pyinstaller Conversor_CAM_DXF.spec
