01 — Visão geral do SISTEMA PPCPM

O que é

Sistema operacional de PCP (Planejamento e Controle da Produção) do Grupo Projeart (indústria metalúrgica). Dono e quem pede as mudanças: Wadson Lima (PCP). Reúne num lugar só as ferramentas do PCP: análise de DBF × FOCCO, geração da Planilha Base, roteiros, impressões, etiquetas Zebra, engenharia (PDF/3D) e os apps de DXF da Preparação fábrica.

As duas versões (sempre iguais na tela)

HTML (navegador) Python (instalado no PC)
Onde roda Vercel: sistemaoperacional-grupoprojeartv92.vercel.app C:\Users\<usuário>\SISTEMA-PPCPM (atalho SISTEMA - PPCPM na área de trabalho)
De onde vem index.html (fonte única) Gerado do index.html por python/gerar_python.py + módulos python/ppcpm/
Atualiza Sozinho a cada envio ao GitHub Sozinho: confere a cada 1 min e avisa "Atualização obrigatória"
Número VERSAO (ex.: Versão 280) pacote (ex.: 57) em versao_python.json
O que só ele faz — Ler/gravar arquivos do PC e da rede, Excel (COM), Zebra pelo cabo, apps DXF, Base Preenchida

Código e publicação

  • GitHub: lima-prog/WS (público), branch main. Cada versão = 1 commit "VNNN: …".
  • Vercel publica o HTML sozinho após cada envio.
  • Supabase (projeto zlbgiodxpywrqapjlldg): login/cadastro, usuários e administradores, dados da Tela inicial (pacotes_impressao: lote, of_trecho, impresso, revisão, observação), alterações de lote, configurações compartilhadas.

03 — Regras fixas e padrões (valem para toda mudança)

SEGURANÇA (obrigatório)

  • Não usar PowerShell em nada (o Bitdefender da empresa bloqueia). Instalar/abrir é por .bat e Python.
  • Nunca pedir para desligar o antivírus.
  • APIs de arquivos só no próprio PC: 127.0.0.1 + cabeçalho X-PPCPM: 1 + conferência do Host (_do_proprio_pc()). Quem acessa pela rede (--rede) não vê os arquivos do Wadson.
  • Claude não digita nem copia senhas, chaves ou segredos pelo usuário.
  • O repositório GitHub é público: o que vai para ele (inclusive planilhas modelo) pode ser baixado por qualquer um.

ROTINA de cada versão nova

  1. Mudar no index.html (blocos src-pgN; dentro deles escrever <\/script>).
  2. Subir VERSAO no index.html e em versao.json; se mudou Python não gerado, subir pacote nos dois versao_python.json.
  3. cd python && python3 gerar_python.py → tem que dizer "remontagem IDÊNTICA".
  4. python3 -m pytest -q → todos os testes passando.
  5. Conferir com prints (Playwright) a tela mudada.
  6. Commit "VNNN: o que mudou", enviar ao GitHub e esperar o Vercel ficar success.
  7. Responder em português; se o pedido veio com print, devolver print do resultado.
  8. Acrescentar a versão no 04_HISTORICO_DE_VERSOES.md (ou regenerar pelo Git).

PADRÃO VISUAL

  • Tema Azul Projeart + ERP clássico: faixa/borda azul #0b3d91, quadros com faixa de título e borda leve, botões cinza-azulado claro (#f3f5f7 → #d9dee5, borda #8f9aa7) com letra preta, cabeçalhos de tabela no tema dos botões.
  • Avisos/perguntas: modelo Modal Azul Projeart (erro = faixa vermelha), arrastáveis pelo título, teclas Esc/Enter.
  • Ícones de linha (SVG), sem emoji; Base fixa = ícone banco de dados com cadeado.
  • Sem barra de rolagem de fora; tema claro e escuro; avisos no idioma escolhido (pt/en/es).

PLANILHA BASE (Agrupador | Base → Gerar Base Preenchida) — sempre assim (V275–V278)

Código: bloco "V275 — REGRAS FIXAS" em validador_fluxos_ppcp.py; resumo em producao/base_fixa/REGRAS_GERACAO_BASE.md. 1. DBF: Classificar (linha 9 = cabeçalho, "Meus dados contêm cabeçalhos", níveis salvos): OF-TRECHO A→Z › Nº LIBERAÇÃO A→Z › MARCA A→Z › PAI X FILHO Z→A. Depois recalcular tudo. 2. Tabelas dinâmicas (DBF até RUPTURA MP): em cada tabela, Alterar Fonte de Dados = DBF!$A$9:<última coluna><última linha COM DADO> e Atualizar. 3. Filtros: PREP_Lista FLUXO PRD = Fluxo 1–4 e FILTRO TD LISTA MAQ. = X; PREP_Quadro tabela PESO POR BC = FLUXO PRD (Tudo); CLEBER = "VP c/ Perfil Lam."; CDI = COMPONENTE LIC, ACESSÓRIOS (vazio), PERFIL LAMINADO (vazio), GRUPO LIC = ESCADA, ACESSÓRIOS, VIGA/PILARES/SOLDADOS, ACESSÓRIOS BARRA, ACESSÓRIOS SOLDADOS; + filtros das observações "<<<" do modelo. 4. PREP_Lista H5 = data do dia. 5. Nomes e cores das abas: DBF (mantém) · FOCCO_VISION_NDPCP301 → FOCCO_VISION_NDPCP399 #ACB9CA · PESO X FLUXO #F4B084 · DET. PCT #66FFFF · PREP_LISTA X MAQ X ORD X TRECHO #666633 · PREP_QUADRO GESTÃO A VISTA #7030A0 · CLEBER_TS x VM x VP x PERFIL #FFD966 · CDI_PROG_PCT #CCFF33 · LT #FF0000 · MARLON_POSIÇÃO_PERFILADEIRA #00CC99 · ELVIS_PERFIL_LAM (sem cor) · RUPTURA MP #FF66FF · BD #3399FF · CALENDÁRIO (mantém). 6. Quadro de aviso no fim lista cada atualização com ✔/⚠ (só com Excel instalado). 7. Nome do arquivo: PPCPM_Programação-Fábrica_Sistema.ppcpm_LOTE_<lote>_<aammdd>.xlsx, salvo em Downloads.

Outras regras combinadas

  • Etiquetas: PERFIL L, PERFIL U/C, PERFIL SOLDADO e TUBO = 1 etiqueta por pacote (mesma lógica).
  • Base fixa e pastas raiz: fixas no sistema, iguais em todos os PCs; o sistema avisa o que falta no PC.
  • Listar PCT existe no Bloco de notas e no Agrupador; digitar à mão continua valendo.
  • Telas não perdem dados ao trocar de aba; janelas abrem no centro e podem ir para a 2ª tela.

05 — Como procurar e como restaurar

Procurar rápido

Quero achar… Onde
Quando uma aba mudou 04_HISTORICO_DE_VERSOES.md → Ctrl+F no nome da aba
O código de uma aba index.html → Ctrl+F id="src-pgN" (número da aba no 02_MAPA_DAS_ABAS.md)
A geração da Planilha Base python/ppcpm/producao/validador_fluxos/validador_fluxos_ppcp.py → Ctrl+F REGRAS FIXAS
Botões/campos do Agrupador index.html bloco src-pg2 (data-w = campo, data-m = ação do Python)
Listar PCT (leitura do print) index.html → Ctrl+F function pctObras / pctCorrigir / ntListarPct
Apps da Preparação fábrica python/ppcpm/fabrica_<app>.py
Versão publicada agora rodapé do sistema ("Versão NNN") e versao.json / versao_python.json

VOLTAR uma versão (quando algo quebrar)

  • Pelo Claude (mais fácil): pedir "volte a aba X para como estava na VNNN" ou "desfaça a VNNN". O Claude acha o commit no 04_HISTORICO_DE_VERSOES.md (código entre crases, ex.: 3c99f5e) e publica uma versão nova com a correção.
  • Pelo GitHub: em github.com/lima-prog/WS/commits/main, abrir o commit da versão → ver o que mudou → "Revert".
  • Um arquivo só: no GitHub, abrir o arquivo → History → escolher a versão → copiar o conteúdo.
  • Nunca apagar o histórico; voltar sempre publicando uma versão nova (assim todos os PCs se atualizam sozinhos).

Restaurar o sistema num PC

  1. Rodar INSTALAR.bat (copia para C:\Users\<usuário>\SISTEMA-PPCPM, cria o atalho e instala as bibliotecas).
  2. Se faltar algo: VERIFICAR_SISTEMA.bat ou janela Verificação da instalação no próprio sistema.
  3. Sem PowerShell e sem desligar antivírus.

Manter este mapa em dia

  • A cada versão: 1 linha nova no histórico; regra nova → 03; aba nova → 02.
  • Pedir ao Claude: "atualize o mapa do sistema" — ele regenera os arquivos e salva nos 3 lugares (pasta X:, GitHub docs/mapa/, projeto Claude).
